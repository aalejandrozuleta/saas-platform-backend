# Code of Conduct

This project is currently maintained by a single developer, but the same
standard applies to anyone interacting with it — issues, discussions, or
future collaborators:

- Be respectful and constructive in all communication.
- No harassment, discrimination, or personal attacks.
- Assume good faith; disagree on technical merits, not people.

Reports of unacceptable behavior can be sent to jhoitan266@gmail.com and
will be handled confidentially.
